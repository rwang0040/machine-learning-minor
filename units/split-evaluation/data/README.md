# B01 批次能耗数据

120 个独立合成批次，固定生成种子 20260927。计划产量为 20—120 件的随机整数，总能耗按 40＋2.5×计划产量＋标准差 15 的正态噪声生成，保留两位小数；最终电费为能耗×0.8，仅作未来信息示例，不代表实际电价或企业记录。

| 字段 | 单位 | 预测时是否可用 | 本次角色 |
|---|---|---|---|
| batch_id | 批次编号 | 是 | 保持行对应，不作预测输入 |
| planned_units | 件 | 是，开工前已确定 | 唯一特征 |
| energy_kwh | kWh | 否，完工后测得 | 标签 |
| final_bill_yuan | 元 | 否，完工后结算 | 排除的未来信息 |

本表无缺失、无重复编号，与 T01 小表分开维护，本次数据无需缺失筛选。实际世界中计划与实际产量可能不同，本合成任务仅用于教学，不能声称具有企业预测效力。

使用 `train_test_split`，固定 `random_state=42`、`test_size=1/3`，得到 80 训练、40 验证，X/y/编号一起划分。各批次按稳定独立过程模拟，故采用随机划分；无设备重复或时间关系。CSV 不存预定 split 列，学生需执行划分并核验。

本单元没有独立最终测试集；验证结果仅用于预设模型比较。无个人信息、无需联网下载；不要把人为生成关系当作真实因果规律。
