# 综合任务：开工前预测质量不合格

这是本课程后半段持续推进的独立合成任务，与课堂能耗/超限数据不同，不直接比较其分数。现在只填写 project.ipynb 中的计划；B05 再建基线，B06 修订处理，T15 冻结，B08 最终评价。

## 问题和数据

在一个独立生产批次开工前，用已确定的 planned_load、temperature_setting、material_score 预测完工后是否质量不合格（defective=1）。三个输入都是无量纲模拟变量，已在预测时可得；不是完工后检测结果。batch_id 是标识，不作特征。

`development.csv` 提供 120 行有标签开发数据。模拟假设批次独立、没有时间依赖或重复设备；可提出固定验证或分层交叉验证计划，但需说明依据。少量输入缺失需要在训练部分/训练折处理。特征数值不是因果结论。

另有 40 行事先保留数据由教师管理，本次不发放标签或计算成绩；最终方案冻结后才用于评价。开发集已公开全部标签，不能事后从中挑一块并声称始终独立未见。
