将基线接入已有综合 Notebook

本目录的 baseline-cells.ipynb 是追加单元格片段，不是替代项目。将其中 Markdown 和代码单元复制到 T08 创建、本人持续维护的 project.ipynb 末尾，保留阶段一问题与划分草稿，不覆盖旧文件。

本片段复用 T08 项目已发布的 120 行开发数据。将片段追加到原项目 Notebook 后，继续使用原项目目录中的 development.csv；路径代码也能从课程根目录找到该文件。学生发行包保留这一份项目开发数据，持续使用同一批记录进行基线与后续比较。

运行前按原计划确认 MODE（cv 或 holdout）、SEED 和 PRIMARY_METRIC。默认 cv=分层三折；holdout=开发集内部固定 25%验证。两个模式只运行选定的一种，不比较两种模式后挑好分数。指标可选 accuracy、recall、precision，须说明任务依据； precision 未定义时不当作有效成绩。

基线每次只学习当前训练部分的多数类。报告开发内指标、混淆计数、可复现设置和局限；不宣称最终测试表现。原计划超出本片段支持范围时按该计划修改，而不是悄悄换成默认方案。

基线运行时保存 baseline_protocol（模式、种子、主指标、实际划分索引），B06 及 T15 用它核对协议是否一致。它是过程记录，不是防止人为重写的安全机制。若已使用旧版片段，先按原书面计划核对设置，再只补协议记录段并按原顺序运行；不得把后来改过的指标登记成最初计划。

本阶段只建一个基线，下一阶段再做有理由的候选改进。短答继续写在同一项目 Notebook 中，不另交报告。
