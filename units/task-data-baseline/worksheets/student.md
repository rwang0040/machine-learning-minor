## D．一个简单基线

只用 H1—H4 的能耗均值，对每个新批次预测同一个数。另有一个给定候选，其 N1/N2 预测值分别为 210、310 kWh。本题只比较预测结果，不研究候选如何得到。

| 新批次 | 实际能耗 | 基线预测 | 基线绝对误差 | 候选预测 | 候选绝对误差 |
|---|---:|---:|---:|---:|---:|
| N1 | 230 | | | 210 | |
| N2 | 320 | | | 310 | |

绝对误差＝预测值与实际值之差的绝对值；平均绝对误差＝两行绝对误差之和÷2，单位 kWh。

1. 两种方法的平均绝对误差分别是多少？
2. 哪个方法在这两行上表现更好？这个结果能说明它对未来所有批次都更好吗？
3. 能否把 N1/N2 的实际值加入均值计算后，再声称这是开工前可用的基线？
