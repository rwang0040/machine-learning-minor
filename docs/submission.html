个人文件、保存与提交

在课程根目录执行下面命令，创建自己的 B01、B02、B03、B04、B05 完整单元副本（将学号替换为自己的标识）：

# WSL / Cloud Studio
.venv/bin/python scripts/prepare-work.py 学号

Windows 使用 .\.venv\Scripts\python.exe scripts\prepare-work.py 学号。副本放在 work/<学号>/units/，数据与 Notebook 的相对关系保持不变；脚本发现已有目录即停止，不覆盖旧答案。分别在对应单元的 labs/ 里完成 Notebook。

已有个人目录的同学，只添加 B03 时使用：

.venv/bin/python scripts/prepare-work.py 学号 --unit regularization

Windows 同样把命令开头替换为 .\.venv\Scripts\python.exe。只会添加尚不存在的 B03 单元，保留原 B01/B02；B03 目录已经存在时仍停止，避免覆盖答案。

  • 记录姓名、日期和辅助工具用途；完成 TODO 后删除该处停止提示，保留检查代码。
  • 提交前重启内核并运行全部，确认输出来自当前代码，保存一份自己的 Notebook。
  • 课末保存到非保护盘并另留可取回副本；云主机持久化按教师说明确认。
  • 每次实验按教师要求提交自己的 Notebook；作业各提交一份按题号组织的答案，清晰手写照片或电子文本均可。

截止日期和提交系统以教师发布为准。不要提交整套课程包、虚拟环境或他人的文件。原模板不保存个人答案，模板更新也不应覆盖 work/。

已有个人目录，添加 B04

.venv/bin/python scripts/prepare-work.py 学号 --unit decision-tree

此命令只添加尚不存在的 B04 单元，不覆盖 B01—B03 或已有答案。项目计划保存在个人副本的 units/decision-tree/project/project.ipynb，后续持续更新同一份文件；本阶段不训练新项目模型。

已有个人目录，添加 B05

.venv/bin/python scripts/prepare-work.py 学号 --unit boosting

Windows 将命令开头替换为 .\.venv\Scripts\python.exe。B05 单元保存于 work/<学号>/units/boosting/。完成实验后，按该单元的 project/README.md，将 baseline-cells.ipynb 追加到原有的 work/<学号>/units/decision-tree/project/project.ipynb。保留原计划和已写答案，继续使用同一份项目文件。
