机器学习辅修：T01—T04 学习材料

本包包含前四章学生材料。讲义是核心学习资料，课件用于课堂演示；作业与实验的具体发布时间、截止时间和提交渠道以教师通知为准。

从 讲义阅读入口 开始，按 T01—T04 顺序阅读。配套材料见 课程地图。

  • 安装与启动：本机或 Cloud Studio 环境、课件 HTTP 浏览。
  • 提交与保存：创建个人实验副本、保存和备份。
  • 作业一 及 作业二：各约 60 分钟，开放讲义和计算器。

所有实验数据均为合成教学数据。B01、B02 仅使用训练与验证，没有独立最终测试集。Notebook 中的 TODO 和停止提示是练习的一部分；按要求补全后删除对应停止提示，保留检查代码。

保留目录结构，不单独搬走 HTML、PDF 或 Notebook。课件内有点击揭示的核对答案；首次交互运行需要联网，不能运行时可使用静态核对。不要把模板更新覆盖到自己的作答文件。

本包为 2026-10-10 本地发布版，记录见 RELEASE.json；不表示已通过实际教室、学生用时或云主机冷启动验收。
