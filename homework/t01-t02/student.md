## 一、把业务目标变成学习任务（20分，建议12分钟）

历史表每天一行，包含以下字段：

| 字段 | 含义与取得时点 |
|---|---|
| `day_id` | 每天记录的唯一编号，仅用于关联记录 |
| `previous_day_visits` | 前一天闭馆后统计的入馆总人次，今天开馆前已知 |
| `morning_reservations` | 今天上午8点之前登记的当日预约人数 |
| `is_holiday` | 今天是否为节假日，开馆前已知 |
| `forecast_rain` | 今天上午7点发布的当日降雨预报 |
| `daily_visits` | 今天闭馆后统计的实际入馆总人次 |
| `actual_rain` | 今天闭馆后汇总的全天实际降雨量 |
| `average_queue_minutes` | 今天闭馆后汇总的实际平均排队时间 |
