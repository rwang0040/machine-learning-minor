抽一条，放回，再抽下一条

原训练记录为 A、B、C、D，每次等概率抽取一条。

  • 放回后，下一次仍可能抽到同一条。
  • 本章抽取次数等于原训练记录数。
  • 这种重新取样称为 Bootstrap 抽样。

同一记录被重复抽中时，输入和标签也重复使用。

Bagging：各自训练，再组合预测

同一份训练记录
抽样 1 → 树 1
抽样 2 → 树 2
抽样 3 → 树 3
同一个新对象 → 各树预测 → 汇总

每棵树使用自己的抽样，训练时无需前一棵树的预测。

Bootstrap 抽样后训练多个基模型，再组合，称为 Bagging。

森林还可以汇总各树的类别概率

同一个对象到达不同树的叶，得到各自的正类概率 pmp_m。

p‾=1M∑m=1Mpm. \bar p=\frac{1}{M}\sum_{m=1}^{M}p_m.

MM 是树数。二分类中，平均负类概率为 1−p‾1-\bar p。

本章实验的森林选择平均概率较大的类别。
